# 英雄与海克斯胜率统计

本功能使用 [AramHex / czgreat/aramhex-data](https://github.com/czgreat/aramhex-data) 的开放汇总数据，按 **CC BY-NC 4.0** 署名、非商用使用。原许可随软件附于 `dist/licenses/aramhex-data-LICENSE.txt`，在线许可为 <https://creativecommons.org/licenses/by-nc/4.0/>。英雄联盟的游戏文本、图标和装备资料适用各自权利，不因统计数据开放而改用此许可。

## 当前快照

- 固定来源提交：`5e6770a1550d2eb40f4da83e31f142e4588524b0`。
- 来源目录：`patches/16.21/normal`，正式服16.21常规规则；对应本项目4.0 / 26.21规则资料。
- 国服7区合并、全分段。各区采集进度不同，这些是来源采集到的样本，不是全服全集。
- 173位英雄，5,141,715场有效对局；采集5,289,394场、排除147,679场。
- 样本开始于2026-10-22，北京时间；截至2026-10-23 11:00的窗口，数据快照时间为2026-10-23 11:13:05（UTC+8）。精确起止时间以随包 `statistics.json` 元数据为准。
- 英雄×海克斯记录23,193条；其中4个新海克斯来源标为测试服暂补，共303条英雄组合记录。这些条目不会与正式服英雄基线相减。

有效对局标准由来源确定：不少于4分钟、10名玩家完整且正好5胜5负、正常结束。重开、提前解散和不完整对局不计。

海克斯统计按**对局结束时持有**计算，同一玩家六个槽位去重。它不是每次三选一选项的随机试验；海克斯选择倾向、出现阶段、英雄阵容和其他海克斯都可能影响观察胜率。任务完成后被替换而导致局末统计失真的“尊我为王”（1337）与内部模板（3176）被来源排除，不会凭空补值。

## 转换与排名

1. 数字英雄ID通过固定的Riot Data Dragon 16.21.1目录映射为本项目英文ID，不靠中文名称模糊匹配。
2. 数字海克斯ID通过当前目录的 `gameDataId` 对应本地slug；未映射条目保留来源原名与统计，不将其冒认为其他海克斯。
3. 校验胜负场次与来源概率相符，将0～1概率转换为0～100百分数；界面计算时使用有效原始 `wins / games`，最后才格式化显示。
4. **胜率差（百分点）= 持有该海克斯样本中的英雄胜率 − 同口径该英雄整体胜率**。只有来源、模式、版本、地区、分段和统计时间一致的记录才计算。未知值保持 `null`，不会变成0%。
5. 排序使用未四舍五入的差值。负数仍显示；来源 `low_sample` 标记的低样本（少于3,000场）默认排除，可手动展开。测试服暂补、非当前目录等参考记录单独标注，不混进正式服可比排名。
6. “我的这一局”为默认首页；英雄胜率榜独立于本局状态，以完整页面宽度显示，不包含本局控制区或加入本局操作。顶部所有功能入口直接展开。

历史选择率仍来自原有 arammayhem.com 26.20 数据集，胜率榜来自此独立 AramHex 16.21 快照。两份数据不混算，原海克斯库的选择率不能当作胜率。

## 装备展示范围

该开放数据集没有英雄×海克斯×装备的条件胜率。展开装备区后只展示装备图标、名字和简短装备效果，不展示玩法路线、购买理由、注意事项或海克斯效果段落。效果摘要取自官方装备目录，保留原有触发条件与否定；装备集合仍根据该英雄、海克斯效果与16.21.1官方装备目录的机制关联生成，不代表装备的统计胜率或统计最优六神装。

## 重跑与来源保护

```powershell
node scripts/update-statistics.mjs
```

更新器固定上述来源提交和16.21正式服规则，核对源文件SHA-256、结构、胜负场次、概率、唯一ID及测试服暂补标记；全部成功后才替换 `dist/statistics.json`。下载和临时数据默认放在H盘任务工作目录。它不是定时监测，也不会把当前时间写作统计发生时间。更换快照需明确更新固定提交及对应校验记录。

本项目对原数据作了ID映射、单位转换、可比性处理和展示，未改变原始胜负场次。数据署名保留AramHex及源仓库链接，适用于对应统计部分。
