# 海克斯指南 · Windows 桌面版

面向英雄联盟海克斯大乱斗玩家的本局助手与资料查询工具。当前源码版本 **1.11.2（测试版，尚未发布）**，默认打开“我的这一局”。加载阶段识别本局双方阵容，只展示推荐装备；进入实战并记录实际选择后，结合所选海克斯、英雄和可读敌方阵容更新装备与后续海克斯方向。辅助页面保留独立全宽入口，英雄胜率原始榜单继续按同口径持有胜率差排序。资料对应 **海克斯大乱斗 4.0 / 26.21**，英雄与装备资料为 **Data Dragon 16.21.1**。

## 1.11.2 自适应扫描（测试版）

重文字识别按阶段和可信等级调度：加载时不扫卡片，普通战斗目标每 5 秒开始一次；首次入场以及跨过 3／7／11／15 级的加强窗口、已有候选时，目标每 1 秒开始一次；6／10／14 级提前提高检查频率。确认后结束当前加强窗口。按剩余时间安排后台检查，并保留完成后的短冷却；耗时超过目标的扫描串行执行，不补扫堆积。手动请求仍立即执行并复用在途任务，轻量点击与选择特效观察频率不变。

具体默认间隔、失败退避、兼容随机事件的兜底及有界诊断见 [扫描调度](docs/ocr-scheduling.md)。这是调度与资源使用优化，不代表单次 OCR 变快、自动确认准确率提高或新版实战验收完成。正在运行的旧版本需另行更新才能生效。

## 1.11.0 当前范围与验证边界

- **加载阶段只推荐装备**：首页和原生侧栏显示我方与敌方阵容，以及装备图标、名字和简短效果；加载阶段不显示三选一控件、已选确认或后续海克斯建议。进入实战后恢复这些功能。每局首次展开，玩家手动收起后保持选择。
- **实际选择后统一更新**：屏幕确认、后续数据来源或手动纠正均通过同一会话边界记录已选；已记录后更新装备与后续适配海克斯。OCR 读到的三个候选不会被当成已选。桌面主页优先使用通过局次、英雄、修订、已选顺序、阶段和时效校验的后台方案；不匹配时立即使用本地同引擎参考。
- **真实统计按英雄查询**：随包 AramHex 快照用于持有胜率参考，ARAMKit 按当前英雄查询单海克斯条件装备、构筑和已公开组合；不预取或打包完整远端数据库。本地有界缓存最多保留最近 **3 位英雄**，区分数据来源、版本和条件范围；缓存失效、缺项或来源不可用时明确降级。已选多个海克斯时，单海克斯条件出装不能冒充完整联合条件统计。
- **装备参考比例**：有可靠数据时，优先海克斯大乱斗 **80%＋普通 ARAM 20%**；普通 ARAM 参考确实不可用时，再使用海克斯大乱斗 **80%＋召唤师峡谷 20%**；辅助来源均不可用时使用海克斯大乱斗 **100%**。这些权重用于各模式内的装备排序得分，不能解释为跨模式混合胜率。主来源也缺失时仅提供明确标注的机制参考，不虚构比例或胜率；页面与侧栏显示实际使用的来源。
- **共享海克斯排序**：资料库适配、英雄适配、三选一与实战候选使用同一政策。先参考可比较的真实持有胜率，接近时再按机制、成长/百分比、固定数值及配置的数值偏好比较；不适用或冲突项不列为优先推荐。低样本与缺失统计明确标注。分类只根据可确认的效果文本或经过审查的例外，因此部分海克斯保留 **unknown / 待判断**，不靠名称强行分类；英雄特殊机制仍需持续补充。
- **实机仍待验收**：当前完成的是源码、离线契约和状态回归。新版加载展示、实际选择后的统计重算及屏幕自动确认的完整连续流程，仍需安装测试版后在真实对局验收。历史单帧识别或合成测试通过，不等于这些流程已经稳定；本版未接通真实 Overwolf 已选事件。下文历史版本与测试记录保留原有时间和证据范围。


## 使用

1. 从[公开下载页](https://hexguide-aram-20261023.robustacorn1025.chatgpt.site/download.html)下载已发布的正式安装包，运行安装向导；本地测试构建可能尚未发布。
2. 选择安装目录，可勾选桌面快捷方式。安装后从桌面或开始菜单打开「海克斯指南」。不需要登录 ChatGPT，也不需要另装 Node.js。
3. 默认进入“我的这一局”。选人阶段尝试同步英雄；进入英雄加载阶段并确认本局双方阵容后，首页与侧栏首次自动展开“开局前预览”，显示我方与敌方英雄，以及推荐装备图标、名字及简短效果；此时不显示海克斯选择和后续建议。进入游戏后接上实际面板与装备；保持三选一卡片在前台游戏中可见，识别成功后自动显示三个候选及推荐排序。
4. 保持三张卡片无遮挡，等侧栏提示屏幕自动确认已就绪，再在游戏内选择。实验功能会核对点击位置、独有选择反馈及卡片收起，证据完整时自动记录并展开构筑；未自动记录时，在助手首页或侧栏点对应海克斯的“记为已选”。推荐随当前装备、已确认海克斯与公开敌方英雄和装备更新；助手不会代你操作游戏。
5. **Alt + Shift + H** 只在英雄联盟对局窗口或助手主窗口位于前台时收放侧栏；浏览器、客户端大厅或其他程序在前台时，快捷键不响应；若后台真实对局画面的客户区仍有可见露出，侧栏按原开关状态继续显示。游戏被完全遮挡、最小化或无法确定露出时暂时隐藏；画面重新露出或返回对局窗口/助手主窗口后恢复原状态：开→开、关→关。独立消息接收器与固定组合备用检测继续共用去重，按住只切换一次。每次启动均紧贴游戏左侧并垂直居中，拖动位置仅本次运行有效。按住 **Ctrl + 鼠标左键** 可从侧栏任意位置拖动，拖动时不会触发按钮或夺走游戏焦点。主窗口收进托盘后自动识别继续；可以在首页或托盘暂停，重启后记住暂停状态。识别失败时再展开手动补录。
6. 顶部完整保留辅助功能入口，各自独立全宽展示。从“英雄胜率”浏览全部英雄和按胜率差排序的海克斯；展开查看共同海克斯、真实条件出装及胜率，不需要启动游戏。
7. 主窗口的“游戏工具”中可收起后台、收放侧栏或返回游戏；托盘菜单“完全退出”才结束助手与本地服务。

自动识别为实验功能，默认开启；后台服务采用阶段与等级调度：加载阶段不扫卡片，入场及 3／7／11／15 级窗口加强，普通战斗低频兜底；具体节奏见 [扫描调度](docs/ocr-scheduling.md)，主窗口隐藏或页面不在实战页也继续。暂停偏好独立保存，重启后保留。识别成功会带入当前三选一，实验性屏幕观察在证据完整时自动确认实际选择；不确定时需手动确认。助手不会替你切窗口、按键或操作游戏。需要游戏卡片保持可见；Windows 没有可用 OCR 语言、布局不兼容、全屏截图失败或名称不确定时，可使用手动补录。**1.10.0 的选择动画尚未完成真实对局校准，合成测试不代表实战通过。**

系统要求：Windows 10/11 x64、.NET Framework 4.8、[Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。当前电脑已有所需运行环境。主程序未作代码签名，不会自行安装服务、修改防火墙或设置开机启动。

安装版通过快捷方式将本局记录和界面缓存保存在 `%LOCALAPPDATA%\HexGuide\data`，卸载保留这些个人数据；安装文件保存在你选择的安装目录。便携版默认在软件旁的 `appdata` 保存本地界面缓存。可用 `HexGuide.exe --data-dir "H:\Chatgpt\hexguide-appdata"` 指定位置。关闭主窗口默认收进托盘；需要停止同步时，在托盘菜单选择「完全退出」。

## 我的这一局与辅助页面

默认首页为“我的这一局”。英雄同步、自动三选一、当前装备与本局构筑集中在同一页；手动补录作为识别失败时的备用入口。OCR 读到完整三个候选后自动比较；屏幕观察确认或玩家手动确认后，展开该海克斯效果、推荐装备与后续关注海克斯。仅卡片消失不会记录选择。重掷、切屏、旧截图、失效轮次、会话变更或重复证据不能沿用为新的确认；人工纠正后也需要新采集才恢复自动确认。

自动确认已独立为可替换的数据来源。目前仅启用实验性屏幕来源，尚未接入真实 Overwolf 已选事件；申请获批后，还须在对应客户端与房间类型中验证数据，再替换屏幕来源。推荐与手动纠正沿用同一套记录逻辑。

加载页预览仅在进入 GameStart 或实时接口尚未准备好的 InProgress、确认本机身份所属队伍且敌方阵容有效时生成。每局首次自动展开，手动收起后不因轮询强行展开；不会激活主窗口或抢游戏焦点。加载时只使用本局英雄和阵容机制，不沿用上一局的海克斯、路线、装备、等级或属性；不把预设当作实战装备或胜率。阵容暂不可读则显示等待，选人阶段不读取敌方名单。进入实战后沿用同一区域继续更新；同一局实时接口短暂中断时等待恢复，不倒退到开局预设。

推荐只使用接口实际提供的公开敌方英雄、等级和装备，不推测技能冷却、隐藏属性或敌方已选海克斯。阵容缺失、过期或不匹配当前英雄时显示未知并停止对应针对性判断。装备与后续海克斯结合可用的同口径统计及可解释机制；实际使用的来源与降级情况单独说明。后续关注列表并非下一轮将出现的候选，也不保证一定出现。

顶部保留全部功能入口。海克斯库、英雄适配、联动查询、英雄胜率与独立三选一页面各占完整内容宽度，不再出现跨页面的本局侧栏。需要英雄条件的工具提供页内英雄切换入口。原有 `#live`、`#library`、`#champions`、`#synergy`、`#stats`、`#compare` 链接继续可用。

网页版首页提供手动管理和查询，自动游戏同步在桌面软件中运行。

## 英雄胜率与海克斯胜率差

从顶部 **英雄胜率** 入口进入统计页。搜索或浏览全部173位英雄；点击英雄后，海克斯按同一统计口径下的胜率差从高到低排列。胜率差使用“该英雄持有该海克斯的胜率 − 该英雄整体胜率”，单位为百分点，按原始胜负场次计算后再显示。它描述样本中的关联，不能保证选择后的因果提升。

数据来自 AramHex 开放数据集的国服7区合并、全分段、16.21常规规则快照；详情显示样本范围、更新时间、场次与来源。默认不列来源标注的低样本（少于3,000场）；参考开关可查看低样本、非当前目录和测试服条目。4个测试服暂补海克斯不会与正式服英雄基线计算胜率差。统计页不显示“我的这一局”，浏览统计不会更改辅助工具中的本局记录。

展开海克斯后，按需从 ARAMKit 读取该英雄选择此海克斯的实战聚合数据，分别显示来源已发布的共同海克斯组合、常见三件套、购买顺序和单件装备胜率。装备保留图标、名字与官方简短效果；数据缺失时不再回退到通用机制装备。组合、构筑与单件装备使用各自样本范围，不会将“英雄＋单海克斯”出装冒充为“双海克斯”出装，也不与 AramHex 基线混算。

随包的 AramHex 榜单数据依 **CC BY-NC 4.0** 署名、非商用使用；ARAMKit 按需查询独立注明来源，不附加该开放许可、不将远端数据打包分发。来源与查询范围见 `README-statistics.md`。榜单快照更新命令为 `node scripts/update-statistics.mjs`。

## 可视化编辑整个界面

点击软件顶部、托盘菜单或页面右下角的 **编辑界面**。进入编辑模式后：

1. 点击页面上的标题、提示、版本栏、英雄区等元素；也可从右侧“当前页面的模块”中选择。层级路径可改选整个面板或它内部的单项。
2. 在右侧修改字体、字号、颜色、底色、内部留白、圆角、宽度和最小高度；选择父容器可以设置列数与间距，子模块可以选择占列。
3. 用选中框上方的抓手拖动，同一组内调整排列；也可直接点上移/下移。元素保留在原有功能分组中。
4. 点 **删除** 从界面隐藏该元素，右侧“已删除的模块”随时恢复；不会删除英雄资料或本局海克斯记录。即使隐藏整个页面，编辑工具仍可使用。
5. 支持撤销/重做（Ctrl+Z / Ctrl+Shift+Z），取消放弃本次编辑；点 **保存并退出** 后重启仍保留。恢复默认先预览，保存后才生效。

布局独立保存在指定数据目录的 `ui-layout.json`，不影响原有字体设置、本局状态或游戏操作。编辑模式会拦住页面内的游戏助手按钮，防止调整排版时误选英雄或海克斯；保存退出后恢复正常使用。此编辑器调整网页界面，游戏侧栏仍使用“界面设置”中的原生侧栏选项。

## 手动调整界面

在主窗口顶部或托盘菜单打开 **界面设置**：

- 主窗口：系统默认、微软雅黑、等线或宋体；整体缩放 85%–130%；网格/列表排列、舒适/紧凑间距、本局面板放左侧或右侧。
- 游戏侧栏：字体、缩放、宽度 280–460 像素、左侧/右侧、透明度 75%–100%；通过上移/下移排列英雄、已选海克斯、本轮候选和玩法建议。
- 主窗口修改可即时预览；点击 **保存设置** 后同步到侧栏并保存在指定数据目录的 `appearance.json`。字体、宽度、透明度和排列等设置重启保留；游戏侧栏的停靠方向每次启动恢复左侧居中，本次运行仍可选择右侧。取消放弃本次预览，恢复默认后仍需保存。

界面设置与本局英雄/海克斯记录分别保存，调整字体或排列不会重置对局或开启识别。

## 游戏侧栏

侧栏是独立的 Windows 原生信息窗，不进入 Alt+Tab 列表，显示和刷新不主动激活窗口。每次启动均紧贴游戏客户区的左侧并垂直居中；按住 **Ctrl + 鼠标左键** 可在侧栏任意位置拖动，放开后在本次运行内保留新位置。拖动期间不触发海克斯选择或其他按钮，也不主动抢走游戏焦点。拖动位置仅存于本次运行内存，关闭后不保存，下次启动恢复左侧居中。跟随游戏窗口调整时会限制在可用范围内，避免移出游戏与屏幕可见区域。本次运行仍可在界面设置选择右侧停靠；字体、宽度、透明度、模块顺序等已保存设置保留。侧栏不提供文字输入，复杂编辑在主窗口完成。1.9.8 只在英雄联盟对局窗口或助手主窗口位于前台时响应 Alt+Shift+H。其他程序在前台时，若后台真实游戏客户区仍有可见露出，侧栏可按原开关状态继续显示；游戏完全被遮挡、最小化或露出情况不确定时暂时隐藏。画面重新露出或返回对局窗口/助手主窗口后，原先开启的恢复显示，原先关闭的保持关闭。临时隐藏不清除原有启用和手动固定状态（Enabled/Pinned）。热键保留独立消息接收器，固定组合备用检测与系统消息共用去重，按住只切换一次，松开后才允许下一次切换。本轮三候选在图标下显示海克斯名称；已选、最近确认和后续关注保留图标展示。海克斯真实品质显示在图标图案内部（alpha 图形内）：白银、黄金或静态棱彩渐变，透明区域保持透明，取消品质边框。三候选中推荐第一使用金色细框，其余使用灰蓝细框；细框只表示推荐，不代表品质。排名为纯文本，名称保留；实际选择仍需点击对应候选确认。热键注册失败或仍未响应时，可使用工具栏或托盘入口；本地有限诊断用于区分注册、触发与侧栏显示状态。

请使用游戏的**无边框或窗口模式**；普通桌面侧栏不能保证盖在独占全屏游戏上。助手不会自行修改游戏显示设置，也不拦截 Alt+Tab 或安装键盘钩子。显示侧栏不等于已验证所有电脑上的切屏兼容性；真实游戏里的焦点切换仍需体验检查。

1.10.0 增加实验性屏幕自动确认及独立的数据来源边界，确认后使用现有逻辑更新装备和后续海克斯。所有完整会话写入校验对局、运行代次及修订号；主窗口首次同步及迟到写入均不能用旧已选列表覆盖新的自动记录。人工纠正优先，旧轮次与重复证据不会重新补回。选择动画阈值仍待真实对局校准，本地合成检查不能作为自动确认准确率保证。当前未启用真实 Overwolf 数据。

1.10.2 将最近扫描的固定原因代码与原生判定的具体拒绝规则分开记录；失败瞬间快照、参考帧年龄、准备持续时间、刷新计数和有界规则汇总用于定位反复取消。仍仅保留单份 4 KiB 诊断，不保存图像或签名。同一轮完整候选、局次和物理位置未变时，新 OCR 更新参考帧而不清空准备状态；鼠标按住和确认中的观察保留原参考帧，继续执行原有即时采集和过期校验。离线测试复现并覆盖了刷新导致的准备盲区及按下/松开之间状态丢失；这两项修复不能作为整条自动确认已通过实战的结论。此次真实等待的具体视觉拒绝分支仍需新版诊断实测。

屏幕结果识别的下一阶段优先核对游戏自身已选图标或完整名称，而不是仅从选择动画推断。当前定义存在不同海克斯共用图标的情况，因此必须限定本轮候选并处理歧义；在取得选后画面样本和验证前，不启用未经校准的结果识别器。设计及证据边界见 [选择结果识别](docs/selection-result-recognition.md)。

## 开发与构建

无需前端依赖安装。Node.js 20+：

```powershell
node --test tests/*.test.mjs scripts/test-engine.mjs scripts/test-version.mjs scripts/test-data-version.mjs
node server/main.mjs --port 0 --data-dir "H:\Chatgpt\hexguide-appdata"
```

开发启动后，首行给出本次本机端口和临时 token；仅用于本机 `/#session=<token>` 启动界面。不要把这行或客户端 lockfile 上传仓库。

Windows 便携版构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -NodePath "C:\path\to\node.exe" -Package
```

脚本从官方 NuGet 下载固定 WebView2 SDK，并校验 SHA-256；使用 Windows .NET Framework 编译器，复制 Node.js 与应用资源，生成便携软件和 ZIP。缓存可用 `-CachePath` 指定；ZIP 可用 `-ArchivePath` 指定。打包排除用户缓存、日志和凭据。运行时二进制不进入 Git，构建脚本与源码保存在私有仓库。

安装版构建（需先构建独立暂存目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -StagePath artifacts/portable-1.11.2
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -StagePath artifacts/portable-1.11.2
```

仅运行自动确认的离线原生测试（不打开窗口、不启动后端、不采集游戏或读取安装版设置）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/test-native-selection.ps1 -ExecutablePath artifacts/portable-1.11.2/HexGuide.exe
```

安装程序以当前用户身份运行，允许选择安装目录与桌面图标，提供开始菜单和 Windows 设置中的卸载入口；详情见 `installer/README.md`。安装包尚未进行代码签名。浏览器下载文件保存位置由浏览器决定，可使用“另存为”或浏览器的下载位置设置。

目录：`dist/` 界面和资料；`server/` 本地采集与接口；`native/` Windows 窗口和 OCR；`tests/` 实时状态和安全检查；`scripts/` 更新与打包。海克斯数据更新见 [README-data.md](README-data.md)，装备更新运行 `node scripts/update-items.mjs`。

公开资料网站：[海克斯指南](https://hexguide-aram-20261023.robustacorn1025.chatgpt.site)。桌面源码私有保存于 [ci16kuai/hexguide-desktop](https://github.com/ci16kuai/hexguide-desktop)。
